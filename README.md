# Rescue Decision Systems

Rescue Decision Systems (RDS) is a prototype pipeline for parsing SARSAT alert
messages and combining alert, weather, satellite, and GIS data.

Documentation starts at [`docs/README.md`](docs/README.md). The verified
codebase status and known limitations are recorded in
[`docs/current/CODEBASE_STATUS.md`](docs/current/CODEBASE_STATUS.md).
